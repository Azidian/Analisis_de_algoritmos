# ☆ Repositorio de Diseño de Algoritmos ☆

Este repositorio contiene las actividades, algoritmos y proyectos prácticos desarrollados durante el curso de Diseño de Algoritmos. Los programas están implementados de manera estructurada en C++.

## ☆ Estructura del Repositorio 

El proyecto se organiza en diferentes actividades y evaluaciones, reflejando el progreso en el diseño y análisis de algoritmos:

- [**`/Actividades`**](./Actividades/): Contiene todas las actividades prácticas, talleres y proyectos realizados durante el curso.
- [**`/Parciales`**](./Parciales/): Contiene los análisis, evaluaciones y parciales realizados en el curso

## ☆ Cómo Compilar y Ejecutar 

Para compilar los programas localmente, necesitas tener instalado un compilador de C++ como **GCC (MinGW en Windows)**.

Para compilar las actividades de un solo archivo (como Karatsuba o Quicksort):
```bash
g++ main.cpp -o programa
./programa
```
